ERES Starlink Indicator

A Chrome extension for United employee travel

Disclaimer: This is an independent, personal project. It is not affiliated with, endorsed by, or supported by United Airlines, Inc. or Starlink/SpaceX. Use at your own discretion.

When you're non-revving, a good flight is one with open seats and, ideally, good Wi-Fi. United is rolling Starlink out across its fleet, but Employee Reservations (ERES) doesn't tell you which flights have it. This extension does: it adds a small marker next to every United flight number on ERES search results and in your travel plans.

What the markers mean

  • Starlink Wi-Fi on the scheduled aircraft
  • No Starlink
  • Unknown (aircraft not assigned yet, or non-United carrier)

Hover over a marker to see the details, like the aircraft type and tail number, or the odds that the flight gets a Starlink-equipped plane if one hasn't been assigned yet.

How it works

The extension reads the flight number, date and route from the ERES page and looks each one up against United Starlink Tracker. Results are cached for the browser session so it isn't re-checking the same flight constantly. It only runs on united.com/EmployeeRes pages, doesn't touch your login or bookings, and doesn't collect or send any of your personal data anywhere.

Install it

Download Extension (.zip)

It isn't on the Chrome Web Store, so you'll load it manually. It takes about a minute:

  1. Download the zip above and unzip it. You should end up with a folder called eres-starlink-extension.
  2. Open Chrome and go to chrome://extensions.
  3. Turn on Developer mode using the toggle in the top-right corner.
  4. Click Load unpacked and select the eres-starlink-extension folder (the one containing manifest.json).
  5. Open (or refresh) Employee Reservations and search for flights. Markers will appear next to the flight numbers.

Keep the unzipped folder somewhere permanent; if you delete or move it, Chrome will remove the extension. This also works in other Chromium browsers like Edge, Brave and Arc.
